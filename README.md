# 稀疏体数据的游程连通组件（RLE Connected Components）

离线、纯标准库的可复用 Python 库：对**三维体按行压缩的半开 x 游程**做
连通组件标记（connected-component labeling），不展开整个体素，任何时刻
只保留当前切片与前一切片的游程。提供两个入口：

* **`label`**：二值体。输出每条游程的组件 ID 以及每组件的体素数、
  轴对齐包围盒、暴露面面积。
* **`label_materials`**：多材料体。同种材料按连通规则合并，不同材料
  即使贴在一起也分开；额外输出每组件材料、对空白（含体积外侧）的
  暴露面积，以及组件对之间的接触面积表。

## 运行环境

* Python **3.14.7**（仅使用 3.14 标准库；不依赖任何第三方包，无需网络）。
* Linux 原生运行；装好 Python 后无需 `pip install` 任何东西。
  仓库里的 `requirements.txt` 无实际依赖内容。

## 准确命令

在仓库根目录执行：

```bash
# 必要测试（独立 BFS 参考 + 手算小例 + 错误语义，覆盖两个入口）
python -m unittest discover -s tests -v

# 固定输入演示：二值三种邻接的不同结果 + 多材料小体（含接触面积表）
# + 两个被实际触发的非法输入拒绝（NaN 坐标、重叠游程）
python demo.py
```

demo 只做真实小规模计算，实测约 0.05 秒（远小于 90 秒），不 sleep、
不读外部数据、不打印预录结果。

## 公开接口

```python
from rle_components import label, Run, BoundingBox, Component, LabelResult

result = label(runs, depth, height, width, connectivity=6)
```

* `runs`：`[z][y] -> [(start, end), ...]`。固定 (z, y) 的一行内，游程为
  沿 x 轴的**半开区间 `[start, end)`**；每行游程必须按 `start` 升序、
  互不重叠（端点恰好相接合法，重叠非法）。游程元素可为
  `(start, end)` 元组/列表、`Run(start, end)` 或
  `{"start": int, "end": int}` 字典。空行用 `[]` 表示。
* `depth / height / width`：z / y / x 方向尺寸，整数，均在 `[1, 512]`。
* `connectivity`：
  * `6`：仅面接触（坐标差 L1 = 1）；
  * `18`：面 + 边（恰两个坐标差为 1），**不含角**；
  * `26`：面 + 边 + 角（三个坐标差均为 1）。

返回 `LabelResult`（frozen dataclass）：

| 字段 | 含义 |
| --- | --- |
| `run_labels` | 与输入同形 `[z][y] -> [component_id, ...]`，顺序对应该行游程 |
| `components` | `Component` 列表，ID 为 1 起始的连续整数 |
| `connectivity` / `num_runs` | 实际连通性 / 输入游程总数 |

`Component` 字段：`id`、`voxel_count`（体素数）、`bbox`（半开
`BoundingBox(min_z,min_y,min_x,max_z,max_y,max_x)`，各区间 `[min,max)`）、
`exposed_area`（暴露面面积，单位为体素面）、`min_z/min_y/min_x`（组件按
字典序最小的体素坐标，即 ID 排序键）。

组件 ID 按组件最小体素坐标 **(z, y, x) 字典序**升序分配。注意该排序键不
必然等于几何包围盒的 `(min_z,min_y,min_x)`：在 18/26 邻接下，几何上
`y`/`x` 更小的体素可能只出现在更大的 `z` 切片（测试中明确覆盖此区别）。

## 公开接口（多材料入口）

```python
from rle_components import (
    label_materials, MaterialRun, MaterialComponent, ContactPair,
    MaterialLabelResult,
)

result = label_materials(runs, depth, height, width, connectivity=6)
```

与 `label` 的区别只在输入游程多一个材料字段、输出多材料与接触信息；
尺寸/游程数上限、连通性语义、ID 排序规则、错误类型完全一致。

* `runs`：`[z][y] -> [(start, end, material), ...]`。`material` 为
  **非负整数**（拒绝 bool/float/负数）；空白区域仍由没有游程表示
  （空行 `[]`、空切片）。游程元素可为 `(start, end, material)` 三元组、
  `MaterialRun(start, end, material)` 或
  `{"start": int, "end": int, "material": int}` 字典。
  排序/重叠/坐标约束与二值入口相同。
* 合并规则：只有**材料相同**的体素才按 connectivity（6/18/26）连通
  合并；不同材料即使面贴面也分属不同组件。同材料但不连通的体素
  照常分成多个组件分别统计。

返回 `MaterialLabelResult`（frozen dataclass）：

| 字段 | 含义 |
| --- | --- |
| `run_labels` | 与输入同形 `[z][y] -> [component_id, ...]` |
| `components` | `MaterialComponent` 列表，ID 1 起始，按最小 (z,y,x) 升序 |
| `contacts` | `ContactPair` 列表：组件间接触面积表 |
| `connectivity` / `num_runs` | 实际连通性 / 输入游程总数 |

`MaterialComponent` 字段：`id`、`material`、`voxel_count`、`bbox`（半开）、
`exposed_area`（**对空白**的暴露面面积，体积外侧按空白计，不含与其他
组件的接触面）、`min_z/min_y/min_x`。

`ContactPair` 字段：`component_a`、`component_b`（保证 `a < b`，每对只
出现一次，按 `(a, b)` 升序）、`area`（两组件共享的方形体素面数量）。
**接触面积只计共享面**：边/角接触面积为 0，选择 18/26 邻接不会多算
面积；只有面积 > 0 的对进入表中。共享面的两个组件必为不同材料
（同材料面相邻必然已合并）。换连通模式使同材料组件合并时，组件编号
与接触表同步更新。结果不依赖输入把一条长游程切成了几段：同材料相邻
游程端点相接必然合并，切分与否的组件与接触表完全相同（测试覆盖）。

## 输入上限（接口边界）

* `depth`、`height`、`width` 各 `<= 512`；
* 游程总数 `<= 20000`；
* 坐标必须为整数，`0 <= start < end <= width`。

这些是硬接口边界，超限一律拒绝；演示与测试不穷举上限规模，但包含
恰为 20000（接受）与 20001（拒绝）的边界测试。

## 错误语义

所有契约违背抛 `rle_components.InvalidVolumeError`（`ValueError` 子类），
消息带可定位前缀（如 `z=0 y=1 run=2.start`），**不静默纠正、不截断**：

* 数值坐标拒绝 `NaN` / `+Infinity` / `-Infinity`；
* 整数参数（尺寸、坐标、connectivity、material）拒绝 `bool`
  （`True/False` 不充当 1/0），也拒绝 `6.0` 这样的 float——必须是真正
  的 `int`；`material` 还必须为非负；
* 尺寸越界、connectivity 不是 6/18/26、空游程、坐标越界、行内游程重叠或
  乱序、嵌套结构尺寸与 depth/height 不符、游程数超 20000、多材料游程
  缺 material 字段等均拒绝。

`label` / `label_materials` 都是无状态纯函数：输入要么完整通过校验后
一次性产出结果，要么抛异常，不存在部分结果或部分变更。

## 算法与设计取舍

1. **扫描 + 并查集**。按 z 递增扫描；每条游程在 DSU 中建一个节点，与
   * 同行前一条游程（仅端点相接时合并，x 方向面接触）、
   * 同切片 `y-1` 行（面/边）、
   * **前一切片的 `y-1`、`y`、`y+1` 三行**（面/边/角）
   做半开区间触达判定后合并。跨切片必须扫三行：(当前 y, 前片 y+1) 这类
   游程对无法靠处理其他行覆盖（两行分属不同切片的不同行）；同切片 y 方向
   则只需扫 y-1，行对 `(y-1,y)` 在处理 y 时恰好计一次。
2. **区间扫描线性化**。行内游程有序，配对时用单调游标跳过不可能触达的
   游程，单行配对为 `O(len(a)+len(b)+触达对数)`，整体近似
   `O(R + 触达游程对)`，`R` 为游程数；区间重叠长度直接给出共享面的
   体素列数。
3. **不展开体素**。内存只与游程数和两个切片相关（DSU 每节点常数个数组：
   父指针、体素数、z/y/x0/x1）。20000 游程量级下实测 26 邻接全稀疏体
   约 0.14 秒。
4. **暴露面积精确计数**。扫描时在 x/y/z 三个面方向各把每个面邻居计一次
   （同游程内部 `length-1` 个面、行内相邻、行间/切片间重叠列），
   `exposed_area = 6 * voxel_count - 2 * internal_face_count`。
   边/角接触不共享体素面，故不影响面积（三种连通性下面积定义一致）。
5. **排序键与包围盒分离聚合**。节点按 (z,y,行内序) 创建，DSU 根第一次
   被遇到的位置即组件字典序最小体素；几何包围盒独立取各轴 min/max。
6. **多材料：同一扫描框架，两处扩展**。触达判定与区间重叠复用二值版
   的单调游标扫描；差别是（a）仅当两条触达游程材料相同时才做并查集
   合并，（b）所有共享面（不分材料）都记录为 `(节点a, 节点b, 面数)`，
   扫描结束后按并查集根拆分：同根 → 组件内部面，异根 → 组件间接触
   面。每组件 `exposed_area = 6V − 2·内部面 − 接触面合计`（体积外侧
   自然落入空白项）。边/角触达只可能触发合并，从不进入面积统计。

## 数值口径 / 误差

模块的全部输出（体素数、包围盒、面积、ID）都是**精确整数运算，不产生任何
浮点结果**，因此不存在浮点误差或容差问题。唯一接触浮点的地方是输入校验：
显式拒绝 NaN/Infinity，且 float 坐标（即使是 `6.0` 这种整数值 float）
不被当作合法整数坐标。

## 测试策略与独立性

`tests/reference.py` 是**完全独立**的参考实现：把游程展开成体素集合后用
BFS 求组件、逐体素逐方向数暴露面；多材料版 `reference_label_materials`
只沿同材料邻居 BFS，并逐体素六方向统计组件间共享面得到接触表。它不导入、
不调用 `rle_components` 的任何代码。`tests/test_core.py`（二值）与
`tests/test_materials.py`（多材料）的随机对照用例以参考实现的输出为
期望值（组件标签、材料、体素数、包围盒、暴露面积、接触表逐字段比对），
另含手算小例和题面点名场景：

* **仅角接触**：`(0,0,0)-(1,1,1)-(2,2,2)` 对角链，6/18 下 3 个组件、
  26 下 1 个；不同材料的角对角在任何连通性下接触面积都为 0；
* **空行/空切片/空体**（两个入口均覆盖）；
* **跨 slice 桥接**：经边接触（dz=1,dy=1）在 18/26 下连通、6 下断开；
* **不同材料交错**：同行端点相接的异材料游程分开，接触面积按共享面计；
* **跨切片相贴**：两切片整面贴合但材料不同，接触面积 = 重叠列数；
* **分段等价**：同材料长游程切成多段 vs 整条输入，组件与接触表完全一致；
* **连通方式切换**：同材料体素经边/角合并时，组件编号与接触表同步更新；
* **单个长游程 / 大实心板**：512 长单游程与 19968 游程的 39×512×512
  实心板（约 1022 万体素）聚合成一个组件且在约 1 秒内完成，验证核心
  保持游程级复杂度、未退化为逐体素工作。

“核心结果自身往返一致”不作为正确性依据，只做补充断言（体素守恒、ID 连续
有序、面积非负、接触对两侧对称且必为异材料等）。

## 已验证的边界

* 尺寸恰为 1 与恰为 512（接受）、0 / 513 / 负数（拒绝）；
* 游程数恰为 20000（接受）与 20001（拒绝，两个入口均覆盖）；
* 端点相接（合法，同材料合并/异材料计 1 个接触面）与重叠、乱序（拒绝）；
* 空游程、坐标越界、NaN/±Infinity、bool/float 冒称整数（含 material）、
  负材料、缺 material 的游程、字典游程多键/缺键（均拒绝）；
* 空行、空切片、整体空体（两个入口，三种连通性）；
* 体积外侧面按空白计入暴露面积（手算小例与参考实现一致）；
* 角/边接触在任何连通性下都不计入接触面积（仅共享面计数）。

## 已知限制（按本题契约的有限子集）

* 只实现本题规定的 6/18/26 三维栅格连通性与按行 x 游程输入，不宣称兼容
  ITK/VTK/`ndimage` 等行业库的全部标签选项、像素类型或流式协议。
* 不做体素展开后的形态学操作、不输出体素级标签体（设计上避免展开）。
* 输入须一次性给出全部切片；不支持增量追加切片的有状态 API。
* 尺寸与游程数上限为题面给定的 512 / 20000；超过即拒绝而非自动外存化。
